# Colombo Family Bot v2

Discord-бот на Python / discord.py для управления заявками, рекрутерами, личными делами, активностью и отпусками.

## Возможности

- заявки через красивую панель и Discord Modal;
- приватная ветка заявки с кандидатом и рекрутерами;
- меню рекрутера: принять / отказать / отложить / вызвать на обзвон;
- автоматическая статистика и лидерборд рекрутеров;
- автоматическая выдача роли принятого участника;
- автоматическое создание личного дела после принятия;
- приватное личное дело участника;
- загрузка скринов/видео активности;
- типы активности: Капт, МП, МШ, тренировка, другое;
- подтверждение или отклонение активности High Staff;
- `/profile`, `/activity_top`, `/inactive`;
- автоматический контроль неактива;
- отпуск/отдых с обработкой Assistant GP Leader / Dep Leader;
- исключение отпускников из контроля неактива;
- SQLite с WAL, индексами и кэшем конфигурации;
- persistent Discord Views после рестарта;
- Dockerfile и health endpoint `/health`.

## Запуск

1. Создайте Discord Bot в Developer Portal.
2. Включите `Server Members Intent` и `Message Content Intent`.
3. Скопируйте `.env.example` в `.env`.
4. Укажите `DISCORD_TOKEN` и `GUILD_ID`.
5. Установите зависимости: `pip install -r requirements.txt`.
6. Запустите: `python main.py`.
7. На сервере выполните `/setup`.
8. Отправьте панели `/panel_application`, `/panel_vacation`, `/panel_case`.

## Northflank

Для сборки используйте Dockerfile из каталога `colombo-bot-v2`. В переменные окружения добавьте `DISCORD_TOKEN` и `GUILD_ID`.

Важно: текущая версия хранит данные в SQLite. Для долгой облачной эксплуатации лучше подключить persistent volume либо перейти на PostgreSQL.

## Безопасность

Никогда не коммитьте `.env` и токен Discord в GitHub. `.env` уже добавлен в `.gitignore`.
