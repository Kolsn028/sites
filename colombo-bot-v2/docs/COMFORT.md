# Удобство Colombo

В категории управления создаётся закрытый канал «управление-ботом». В нём панель High: очередь проверок, заявки, отдых, МП, поиск игрока и статистика. Все кнопки проверяют роли при нажатии; доступ к карточкам остаётся High и выше. Ссылки из очереди не меняют права приватных веток.

/management открывает ту же панель лично. /my_requests или кнопка «Мои заявки» под панелью набора показывает только собственные обращения. Есть фильтр по виду, страницы и обновление. Чужие данные не выбираются из базы.

В МП нажмите «Создать сбор» → «Сегодня», «Завтра» или «Другая дата». Для первых двух вариантов достаточно времени 20:00. Время московское. Места и описание подставляются из последнего опубликованного сбора этого вида на этом сервере, их можно изменить.

В меню «Управление» у сбора доступно «Повторить сбор». Оно переносит параметры именно выбранного МП, но не дату, участников и отметки. Старый сбор сохраняется, новый публикуется только после отправки формы High. Семейная роль получает обычное уведомление о новом сборе.

При заполнении основы бот предлагает резерв; при заполнении резерва сообщает об этом. Удалённые каналы/сообщения и неверное время имеют конкретные подсказки.

Повторный /setup для установки не нужен. Данные и привязки сохраняются через действующие копии Discord.
