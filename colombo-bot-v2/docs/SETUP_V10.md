# Настройка Guest / Colombo / Test

После обновления выполните `/setup` или `/setup_auto` от Ass.Deputy, Deputy Leader, Leader либо владельца сервера. Выберите роли из списка Discord:

| Поле | Роль |
|---|---|
| guest | Guest |
| colombo | Colombo |
| test | Test |
| main | main |
| recruit | Recruit- |
| ass_deputy | Ass.Deputy |
| deputy | Deputy Leader |
| leader | Leader |
| vacation | Отдых |

Поле novizio оставьте пустым: это совместимый старый вариант поля test. Guest, Colombo и Test должны быть разными ролями ниже роли бота.

При входе выдаётся только Guest. При принятии заявки выдаются Colombo и Test, затем снимается Guest. Если выдача или снятие не завершились, решение не закрывается: повторите приём после исправления прав. При повышении main заменяет Test, Colombo остаётся.

Настройка больше не выдаёт Guest или Colombo всем подряд. У участников с Test/main добавляется Colombo и снимается Guest; у тех, кто уже имеет Colombo, снимается Guest. Новички без семейного ранга не меняются. Участники в отпуске или с незавершённой заявкой на отпуск пропускаются, чтобы не нарушить восстановление.

Каналы семьи и плюсов МП доступны Colombo, Test, main и старшим ролям. Каналы набора видны @everyone. Произвольные существующие каналы, которые не управляются ботом, нужно настроить отдельно.

Новая заявка уведомляет только рекрутов. До назначения ветку видит состав проверки; после «Взять заявку» остаются заявитель и ответственный. «Освободить заявку» снова открывает её проверяющим. Администраторы Discord и владелец сервера имеют системный доступ. В родительском канале заявок отключается обход приватности через Manage Threads для обычных ролей и участников; бот сохраняет управление.

При создании сбора тегается только роль Colombo, включая старших участников с этой ролью. Для этого бот должен иметь право упоминать все роли в канале либо Colombo должна быть упоминаемой. Изменения состава повторных уведомлений не отправляют.

Проверка: `/config_show` показывает сохранённые роли. Введите `/setup` заново, если Discord показывает старые параметры.
